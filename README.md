# 복귀마을

막 전역해서 뭘 해야 할지 막막한 사람들이 모이는 온라인 마을이에요.
아바타를 만들어 마을을 걸어 다니며, 건물마다 정보와 경험을 나누고 서로의 다짐을 응원해요.

> 아직 개발 중인 프로젝트예요. 지금 바로 들어가 볼 수 있어요: **https://homecoming1020.fly.dev**

## 이런 마을이에요

마을에는 여섯 개의 건물이 있어요.

| 건물 | 이야기하는 것 |
|---|---|
| 💼 취업 지원본부 | 공채·수시채용, 이력서, 면접 준비 |
| 📚 자격증 교육대 | 자격증·어학·공시 준비 스터디 |
| 📅 전역 준비 막사 | 곧 전역하는 사람들을 위한 준비 공간 |
| 🧳 휴가 센터 | 여행, 워킹홀리데이, 해외 경험 |
| 🍵 충성마트 쉼터 | 막막할 때 나누는 마음 이야기 |
| 🔥 내무반 썰방 | 군대에서 있었던 일, 웃긴 썰·힘들었던 썰 |

## 주요 기능

- **걸어 다니는 마을**: 방향키·WASD로 걷거나, 바닥을 클릭·탭해서 이동해요. 휴대폰에서도 돼요.
- **실시간 접속**: 같은 시간에 들어온 사람들이 서로 보여요. 동시 접속은 최대 100명이에요.
- **채팅 말풍선**: Enter를 눌러 한마디를 하면 머리 위에 말풍선이 떠요.
- **경례 구호**: 입장할 때 `충성`, `필승`, `단결` 같은 구호를 스크롤로 골라요.
- **건물별 글·댓글·좋아요**: 방마다 글을 남기고 댓글을 달아요. 좋아요는 글마다 한 번만 누를 수 있고, 좋아요가 많은 글 두 개가 위에 올라와요.
- **오늘의 다짐**: 다짐을 적으면 광장에 내 등불이 걸려요.
- **놀거리**: 벤치·통나무에 앉기, 그네, 분수 소원 빌기, 축하 폭죽, 감정 표현(1~5 또는 "표정" 버튼).
- **신고와 운영**: 부적절한 글·댓글은 🚩로 신고해요. 운영자는 `/admin`에서 삭제·복구하고 기록을 백업해요.
- **낮·노을·밤**: 실제 시간에 맞춰 하루가 흘러가고, 밤에는 창문과 가로등이 켜져요.

## 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org/)가 필요해요.

```bash
npm install
node server.js
```

브라우저에서 `http://localhost:3000`을 열면 돼요.

- 화면 왼쪽 위에 **"접속 중 N명"**이 보이면 서버와 연결된 거예요.
- `index.html` 파일을 더블클릭해서 열면 서버 없이 **오프라인 예시 모드**로 열려요. 가짜 주민이 돌아다니고, 글은 내 브라우저에만 저장돼요.
- 서버는 `Ctrl + C`로 끄는 걸 권해요. 꺼질 때 마지막으로 기록을 저장해요.

## 기록은 어디에 저장되나요

사람들이 남긴 글, 댓글, 좋아요, 등불은 서버의 `data.json` 파일에 저장돼요.

- 서버를 껐다 켜도 남아요. 저장 위치는 `DATA_DIR` 환경 변수로 바꿀 수 있어요.
- 하루에 한 번 백업(`data-날짜.bak.json`)이 생기고 최근 14개를 보관해요.
- 이 파일에는 좋아요를 누른 브라우저의 고유 번호가 들어 있어서, **공개하거나 GitHub에 올리면 안 돼요.** `.gitignore`가 막아 줘요.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체(마을 그림, 조작, 글·댓글 창) |
| `server.js` | 실시간 서버(접속·이동·채팅·글·댓글·좋아요·신고·저장·도배 방어·운영자 API) |
| `admin.html` | 운영자 페이지(`/admin`): 신고 확인, 삭제·복구, 백업 내려받기 |
| `favicon.svg`, `og.jpg` | 브라우저 탭 아이콘, 링크 공유 미리보기 이미지 |
| `fly.toml`, `Dockerfile`, `.github/workflows/deploy.yml` | 인터넷에 올리는 설정(Fly.io, 자동 배포) |
| `DEPLOY.md` | 배포 방법 안내 |

## 알아두세요

- 로그인이 없어요. 이름은 누구나 정할 수 있고, 좋아요는 "브라우저 하나당 한 번"으로 세요. 브라우저 저장 데이터를 지우면 다시 누를 수 있어요.
- 글·댓글 삭제는 운영자만 할 수 있어요(`ADMIN_KEY`를 정해 두어야 해요. [DEPLOY.md](DEPLOY.md) 참고). 내 컴퓨터에서 시험할 때는 `ADMIN_KEY=아무비번 node server.js`로 켜면 `http://localhost:3000/admin`을 쓸 수 있어요.
- 부대 이름·위치, 훈련 내용 같은 군사 기밀이 될 수 있는 내용과 실명 비방은 올리지 마세요.
